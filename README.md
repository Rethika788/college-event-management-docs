# College Event Management System

## Introduction

The College Event Management System is a web-based application used to manage college events.
It helps students and staff view, organize, and manage college events easily.

## Features

- Create college events
- View upcoming events
- Student event registration
- Manage event details
- View registered participants
- Generate event reports

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Download the project.
2. Open the project folder.
3. Open index.html in a browser.

## Usage

1. Open the College Event Management System.
2. View the available college events.
3. Select an event.
4. Register for the event.
5. View event details and registration information.
